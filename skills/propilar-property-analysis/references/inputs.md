# 入力の集め方

## 必須（これがないと分析しない）

| 聞くこと | ツールの引数 | 単位変換 |
|---------|------------|---------|
| 購入価格 | `purchasePrice` | 万円 → 円 |
| 想定月額家賃（満室時の合計） | `assumedMonthlyRent` | 万円 → 円 |
| 借入額 | `loanPrincipal` | 万円 → 円。購入価格以下 |

家賃が「表面利回り◯%」でしか分からないときは、`購入価格 × 利回り ÷ 12` で月額家賃に直してから渡し、そう換算したことをユーザーに伝える。

## あれば聞く（なければ既定値）

| 聞くこと | 引数 | 既定値 | メモ |
|---------|------|-------|------|
| 金利 | `annualInterestRate` | 0.02 | % → 小数 |
| 返済年数 | `repaymentYears` | 20 | |
| 空室率 | `vacancyRate` | 0.05 | % → 小数。地方・築古は 0.1〜0.15 も検討 |
| 構造 | `structureType` | `rc` | 木造 `wood`、軽量鉄骨 `light_steel`、重量鉄骨 `heavy_steel`、RC `rc`、SRC `src` |
| 築年月 | `builtYearMonth` | `2000-01` | `YYYY-MM`。年だけ分かれば `YYYY-01` |
| 建物価格 | `buildingPrice` | 購入価格の30% | 減価償却に効く。土地は残り |
| 保有年数 | `holdingYears` | 10 | IRR・売却の計算に使う |
| 購入年月 | `purchaseYearMonth` | 現在 | |

既定値を使ったときは、どれを仮定したかを結果と一緒に伝える。

## 自動で見積もられる費用（ユーザーには入力させない）

仲介手数料（価格×3%+6万円、税込）、管理費・修繕費（年間家賃の各5%）、火災保険（年5万円）、固定資産税（価格×1.4%）、所得税・住民税（20%・10%）、譲渡所得税（保有5年超 20.315%、以下 39.63%）、割引率 4%、売却費用 4%。

区分マンションの管理費・修繕積立金はこの見積もりに含まれない。
